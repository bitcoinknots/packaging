Bitcoin Knots packaging
=======

Bitcoin Knots is packaged and distributed through different channels.

Installers and pre-built binaries for Windows and macOS and Linux are available for download from [https://bitcoinknots.org](https://bitcoinknots.org) and [https://github.com/bitcoinknots/bitcoin/releases](https://github.com/bitcoinknots/bitcoin/releases).

There are also packages distributed at:
[https://launchpad.net/~luke-jr/+archive/ubuntu/bitcoinknots](https://launchpad.net/~luke-jr/+archive/ubuntu/bitcoinknots).

In addition, this repository contains packaging metadata for package managers running on Linux. Currently

* [Snappy](/snap)
* [Debian](/debian)
